# Teammed 

A medical consultation management platform built with Flask, designed to streamline the interaction between doctors and patients.

## Features

**For Patients**
- Register and manage your profile
- Book appointments based on doctor availability
- View consultation history and uploaded files
- Track personal health stats with interactive charts

**For Doctors**
- Manage weekly schedules and block off exceptions
- View and manage all assigned consultations
- Upload consultation files and notes
- Dashboard with patient statistics and Plotly.js visualizations

## Tech Stack

- **Backend:** Python, Flask, SQLAlchemy
- **Frontend:** Jinja2, HTML, CSS, JavaScript
- **Database:** SQLite
- **Libraries:** FullCalendar.js, Plotly.js

## Setup

1. Clone the repository
```bash
   git clone https://github.com/dragos-vs07/Teammead.git
   cd Teammead
```

2. Install dependencies
```bash
   pip install -r requirements.txt
```

3. Create a `.env` file in the root directory
